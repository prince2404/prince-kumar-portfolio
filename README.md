# Prince Kumar | Java Backend Developer Portfolio

A clean, fast, accessible portfolio website built with **Next.js 15 (App Router)**, **Tailwind CSS**, **Framer Motion**, and **TypeScript**.

## Highlights
- **Simple, recruiter-friendly wording**: Easy to scan in under 30 seconds for both technical and non-technical visitors.
- **Strict Color Palette**: Midnight Black (`#030407`), Electric Cobalt Blue (`#1558C9`), and Acid Lime (`#D4FF24`).
- **Hero Photo**: Optimized `public/images/prince.jpg` loaded via `next/image` with `priority`.
- **Resume Download**: Pre-loaded at `public/Prince_Kumar_Resume.pdf`.

---

## Run Locally

1. Extract the zip archive and open the folder in VS Code or IntelliJ IDEA.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Run the development server:
   ```bash
   npm run dev
   ```
4. Open [http://localhost:3000](http://localhost:3000).
